# Compatibility verdict worksheet — write by hand

The **verdict** is the single bold line that closes each compatibility planet card, after the
function line and the two placements. One sentence. It should conclude *these* two placements and
reference the actual pairing (element/axis), not a generic category.

It's keyed by pairing bucket. Below is every slot that needs a line, for all 7 planets. Write in the
blank. If you want one line to cover a whole bucket (e.g. a single opposition line instead of two),
just write it once and I'll collapse the key. Leave a slot blank and I'll flag it, not fill it.

**Buckets** (same for every planet):
- Same sign
- Same element → Fire · Earth · Air · Water
- Complementary → Fire+Air · Earth+Water
- Friction → Fire+Water · Earth+Air
- Mixed → Fire+Earth · Air+Water
- Opposition → Fire/Air axis · Earth/Water axis

Element members: Fire = Aries/Leo/Sagittarius · Earth = Taurus/Virgo/Capricorn · Air = Gemini/Libra/Aquarius · Water = Cancer/Scorpio/Pisces
Opposition axes: Fire/Air = Aries–Libra, Leo–Aquarius, Gemini–Sagittarius · Earth/Water = Taurus–Scorpio, Cancer–Capricorn, Virgo–Pisces
