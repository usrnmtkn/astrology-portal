# Flagged vague phrases (raw material for the lived-experience bank)

Scanned across the 7 compatibility card files + ASPECT-MEANINGS-REFERENCE.md. Each entry is a phrase that
names a quality or a result without showing the lived moment. Counts = occurrences. Grouped by type, with
the "name the X" direction and real example lines pulled from the copy, so you can write the lived version.
Same principle as the reassurance / stay-safe / leaned-on / steadiness bank: do not swap one abstraction for
another, name what the two people actually do.

---

## 1. Connection verbs — "how you click" (biggest bucket, ~208 total)

These hide *how* the two people actually fit. Name the specific exchange: what one gives, what the other
gives back, in a concrete moment.

- **"understand each other" / "you understand each other"** (94) — often "on sight," "without a word,"
  "without explaining." Name what they actually pick up: a look that says drop it, knowing to bring food
  not advice, not needing the backstory to know why the other went quiet.
- **"round each other out"** (29) — Name the trade. Ex: "Because you can help {friend} name what's wrong and
  {friend} can teach you to actually feel it, you round each other out…"
- **"complete each other"** (30) — usually "opposites like this can complete each other." Name the swap: what
  each hands the other that they couldn't do alone.
- **"help each other"** (29) — Name the help. What does one do for the other on a hard day.
- **"you balance" / "you balance each other"** (24) — Name the counterweight. Ex: "Because {friend} can loosen
  you up and you give {friend} something solid to land on, you balance…" (what is "something solid to land
  on" in a real moment?)
- **"stretch each other"** (18) — Name the stretch. Ex: "you can give {friend} perspective and {friend} can
  pull you into feeling, you stretch each other…"
- **"pull each other's level"** (14) — Name it. Ex: "you can lighten {friend} and {friend} can give you
  something with weight, you pull each other's level…" ("something with weight" = what, exactly?)
- **"you connect"** (5) — Name the connection: over what, doing what.

## 2. Attraction abstractions — "there's a spark" (~26 total)

These assert a pull without showing it. Name what actually draws them, or what one does that the other can't
look away from.

- **"the pull is strong"** (12) — Ex: "you're both fixed and fascinated by what the other is, the pull is
  strong…" Name the fascination: what does the other do that you keep watching.
- **"a real pull" / "there's a real pull" / "real draw"** (8) — Name the draw.
- **"real force"** (3) — Name what the force looks like when they use it.
- **"real devotion"** (2) — Name the devoted act.
- **"the charge is real"** (1) / **"deep loyalty"** (1) — Name the charge / the loyal thing they do.

## 3. Build placeholders — "you make something ___" (~34 total)

"Something" is the tell. Name what they build or what it looks like from the outside.

- **"something solid"** (17) — a life that holds, a routine you both keep, a home that runs.
- **"something real"** (10) — name it.
- **"something lasting"** (4) / **"something powerful"** (2) / **"a durable team"** (1) — name what lasts or
  what the team actually does well together.

## 4. Ease — "it just works" (~21 total)

Name what easy looks like day to day.

- **"it flows"** (18) — Ex: "Because you both like things calm, it flows…" Name the calm: quiet mornings, no
  drama over plans, agreeing without a fight.
- **"it clicks"** (3) — name the click.

## 5. Difference / outcome — the clash (~15 total)

Name the actual moment the difference shows up, not the category.

- **"you clash on X"** (10) — e.g. "clash on pace," "clash on ego and reason." Name the scene: one's already
  moved on while the other is still deciding; one wants it out loud, the other won't say it.
- **"meet in the middle"** (4) — name the meeting: who moves, how far.
- **"pull in different directions"** (1) — name the two directions in a concrete moment.

## 6. The unspoken — what doesn't get said (~13 total)

Name the specific thing that stays unsaid.

- **"goes unspoken"** (5) — the actual sentence neither says out loud.
- **"the deeper feeling"** (4) — name the feeling that gets skipped.
- **"never gets faced"** (4) — name the problem that gets avoided.

## 7. Reaction states — the friend's feeling (~13 total)

Partly covered by the earlier bank. Name what the person *does* that creates the feeling.

- **"feels crowded"** (8) — Name it: you text again before they've answered the first; you move closer when
  they've gone quiet.
- **"feels unmet"** (3) / **"feels held off"** (1) / **"feels shut out"** (1) — name the moment the door closes.
