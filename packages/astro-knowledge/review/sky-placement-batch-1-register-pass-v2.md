## Mercury in Gemini

**Opening**
Mercury in Gemini makes an unfinished question hard to leave alone. From {{entryDate}}, one vague
message can set off a chain: someone finds the original source, someone else spots a contradiction,
and the group chat fills with links, screenshots, and sharper questions. It feels good. We are
learning fast, talking it through, getting closer. Mercury moves through all twelve signs in about a
year because it stays near the Sun. It usually spends two weeks to two months in a sign, longer in a
retrograde year.

**Tension**
The missing fact gets found, and the search keeps going anyway. Each answer suggests another angle.
We open more tabs, add side questions, reply to the newest message before asking whether it changes
anything. The clever summary gets repeated because it is quick. The slower source that contradicts it
goes unread. By the time a choice has to be made, nobody can tell which version is current. The
conversation is still lively. It has just stopped helping.

**Development**
Curiosity is not the problem. We can go back to the original question, keep what is confirmed, and
let the rest be interesting instead of urgent. When a correction comes, someone can say it plainly
instead of adding another theory. The side questions can wait in a note. The chat gets shorter, and
the choice gets easier, because everyone is finally working from the same checked facts.

**Close**
Before {{exitDate}}, we can close the tabs and make the pending choice from the facts we have
actually checked.

**Try this**
- We can read the original source before forwarding a summary.
- We can delete a clever sentence from a draft when the source does not support it.
- We can turn off the chat alerts while we read the thing everyone is discussing.

## Mars in Scorpio

**Opening**
Mars in Scorpio brings the nerve to question a story that no longer adds up. As Mars enters Scorpio
on {{entryDate}}, the evidence may be ordinary. A shared commitment changes without warning. One
reply says it was sudden; another shows it was decided weeks ago. A direct question gets silence. So
we compare what was said, name the contradiction, and stay in the uncomfortable conversation until
the real issue is on the table. Mars moves through all twelve signs in about 2 years, spending six to
seven weeks in each, longer in a retrograde.

**Tension**
Once the contradiction is confirmed, stopping feels like giving up control. We reread every message
for a second betrayal. We ask the same question in new forms. We hold back what we know, waiting to
see whether someone lies again. Silence becomes a test instead of a pause. And the other side,
feeling watched, starts guarding every word, which gives us more silence to read into.

**Development**
What helps is separating what happened from what we suspect it means. Name the broken promise. Ask
for the missing fact. Say what decision depends on the answer. If the story keeps shifting, we do not
need a confession to change the terms or step away. If the answer is honest, more investigating only
keeps the conflict hot. Either way, saying what changes now ends the private tests.

**Close**
Before {{exitDate}}, we can leave a commitment whose terms were broken and never honestly explained.

**Try this**
- We can reread a tense message thread and write down what was said separately from what we suspect it means.
- We can say what we already know instead of waiting in silence to see whether someone admits it.
- We can delete a hostile draft instead of sending it just to make someone feel the same anger.

## Saturn in Aries

**Opening**
Saturn in Aries makes one pattern obvious: we wait so long to act that every move comes out as a
fight. From {{entryDate}}, a needed decision sits untouched while we wait to feel certain. Then
waiting becomes unbearable, and the decision comes out as a declaration. It is finally made, but now
it has to be defended. Saturn moves through all twelve signs in about 29 years and stays two and a
half to three years in each, which is enough time to learn a less punishing way to begin.

**Tension**
Going first cleared the standstill once, so it becomes the answer to everything. We decide before we
are ready. We refuse help before anyone offers it. A question sounds like resistance. A simple limit
comes out as a hard refusal, but only after too much has already been accepted. The pressure drops
each time, and each time there is a new position to defend.

**Development**
The work is not waiting for certainty, and it is not crushing the impulse. It is giving courage time
to become deliberate. When a choice feels urgent, we can split off the part that must happen now and
let the rest stay undecided. When a limit is reached, we can say it while the words are still calm.
And accepting help does not cost independence. It keeps independence from becoming a test nobody
asked us to pass.

**Close**
Before {{exitDate}}, we can stay with one chosen direction and adjust the pace instead of abandoning
it or forcing it.

**Try this**
- We can say one no plainly the first time, instead of agreeing now and refusing sharply later.
- We can make the smallest useful start on something delayed and stop after that start is complete.
- We can accept one concrete offer of help without taking the task back midway.
