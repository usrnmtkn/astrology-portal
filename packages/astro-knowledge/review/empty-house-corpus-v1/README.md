# Gemini empty-house corpus V1

Status: superseded draft lineage; never reader-serving.

This package preserves the corrected 309-entry Gemini corpus, its writing
prompt, rubric, and deterministic validator. V14 is the canonical approved
source. The corpus remains useful for lineage comparisons and mechanical QA,
but its prose must not override an overlapping V14 key.

The original validator result was 309 entries checked with 0 errors and 52
warnings: 13 pivot advisories and 39 seven-gram overlap advisories. Its
`ruler-opener-direction` check describes the superseded corpus style and does
not apply to V14's direct scene-led ruler copy.
