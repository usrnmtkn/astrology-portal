# Weekly owner-evidence bridge

## Scope and finding

This repair changes the canonical Weekly preparation, writer request and private
Studio receipt. It does not certify voice quality or change saved instructions.

The old primary selector admitted twelve complete Weekly readings because it
recognized only one source heading format. The existing governed corpus contains
four Weekly articles with 48 complete sign readings. Separately, saved profile
comparisons already entered the writer through source guidance. A claim that the
writer received only twelve examples conflates these two paths.

## Delivery contract

- Verify registered article hashes, ordered sign boundaries and positive authority
  for every paragraph. Preserve each complete contiguous sign section, including
  all paragraphs. Reject changed sources; exclude units with revoked paragraphs.
- Retrieve from 48 Weekly units plus 39 complete Seasonal units and one complete
  Monthly unit using existing loaders and manifests. Supplemental articles do not
  change the compact Weekly length/register contract.
- Record lexical matches to the saved outline, life areas and calculated meaning
  packet. Do not boost the example's historical Sun sign. This is auditable word
  matching, not semantic selection by psychological mechanism.
- Preserve complete saved profile comparison blocks and correction text. Verify
  comparison hashes even when the prompt uses only its original four variables.
- Carry the latest rejected reading for the same edition and sign as complete
  negative evidence. Do not infer a rejection reason or widen its scope.
- Before dispatch, assert that each selected complete passage is present in the
  assembled input. Save the exact provider request, final instructions, input hash,
  source texts/hashes, selection inventory, corrections and route in private
  generation metadata. The canonical harness also retains its assembled request.
- Pass the same complete evidence to the existing independent rhetorical reviewer.
  That reviewer checks three rhetorical protections, not overall voice fidelity.
- Display selected complete evidence in Generate and the persisted request in
  Review. Older readings without receipts say so; never reconstruct their inputs.
- Keep private evidence out of the public reader projection.

## Remaining boundaries

This is not a universal inventory of everything the owner has ever supplied.
Unregistered private references are not silently promoted into a public corpus.
Saved comparison authorship and approval are not inferred from their presence in
a profile. Studio feedback currently scoped to other content families is not
silently admitted to Weekly. Semantic retrieval beyond lexical matching and broad
voice review remain separate work. Receipt verification proves delivery, not
quality, approval or production freshness.

Before release, run the full Content Studio API contract on the final PR head,
provision and run the private privacy guard and built-asset scan, and follow the
normal main-branch deployment process. No commit, push or deployment is included
in this local acceptance record.
