# 2. Source lock

Allowed edits:

- remove the event subject so the source fits after `while the {{selectedMoonEvent}}`
- change `you/your` to `we/our` for collective grammar
- fix an obvious grammatical error
- remove an em dash or an older banned construction
- trim surrounding sentences

Not allowed:

- combine separate ideas into a new interpretation
- fill a missing sign/event combination from generic astrology knowledge
- write a new line because it sounds similar to Project Author
- label model-written synthesis as owner copy

If no owner sentence is verified, use:

```text
status: NEEDS OWNER COPY
copy:
```
