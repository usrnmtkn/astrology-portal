# Horoscope instruction-stack release

This release carries the reviewed Weekly, Monthly and Seasonal refinements onto current clean main. It does not carry the earlier worktree's unrelated Content Studio edits or Daily experiments. The original worktree remains preserved.

## Scope

- Weekly, Monthly and Seasonal use a concise prose instruction block that follows the saved profile's source order, format and ending rules. Repeated app authority is consolidated; complete meaning/style evidence and integrity receipts remain.
- Weekly receives only the requested rising sign's house bindings, while retaining the complete signed calculation packet. Its approved format, vocabulary and complete source passages are preserved.
- Monthly's app wrapper follows the current saved source priorities and consolidates repeated synthesis/specificity directions. Its existing source deduplication remains intact.
- New Seasonal preparations allow an unsupported distinction, changed understanding or response to be explicitly absent. Their planner and reviewers accept an unresolved reading. Older frozen preparations keep their original schema and instructions.
- The transport no longer requires a fixed opening for explicit server-selected instruction text. Default role instructions, authorization, request equality, source integrity, schema validation and approval boundaries remain.
- Explicit Weekly and Monthly profile proposal builders preserve complete Source guidance. They never rewrite or activate saved profiles automatically. Profile activation is a separate version-checked operation.

The newer main fixes for source references, feedback timestamps, ingress instructions, scoped Ghostwriter guidance and Sky workspaces remain. No source bank, dependency, UI component, model selection, token ceiling, stage count, retry budget or publication rule is changed.
