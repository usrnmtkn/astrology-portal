# Sky and Calendar aspect standard integration

The owner supplied the complete [planetary aspect standard](SKY_CALENDAR_ASPECT_STANDARD.md)
on November 8, 2026 and authorized application, checks and deployment on November 9
in `thread:01a1b1a6-37cb-7772-bdf0-0adeb14be2cb`.
The document is retained verbatim, SHA-256
`b44b58dcaccfd78b85d9a37109e2a974394cc006c2e66f835d24819238ff8e13`.

It governs new collective sky-to-sky aspect drafts shared by Sky and Calendar.
It replaces the older aspect-only eight-beat/two-paragraph template, forced
warmth placement and truth-plus-catch ending. It preserves the existing shared
vocabulary, contextual rhetorical review, factual/source boundaries, provider
settings, retry limits, output schemas and owner-only publication decision.
Saved reader copy, approved sources, profiles and stored requests are unchanged.
Other writing families retain their existing authority.

`build-sky-aspect-writing-standard.mjs` generates the complete runtime artifact
from the exact document. `skyAspectEditorialAuthority.cjs` supplies it once in
the system instructions for both providers. The CMS/cron aspect generator and
the shared generation handler use this scoped authority; the latter has a
separate collective-aspect request builder so generic natal, scene and advice
instructions cannot compete with it. Paragraph/closing-shape heuristics are
advisory for collective aspects, and advisory notes are excluded from lint retry
instructions. Existing lexical and reader-boundary failures remain enforced.

New generation receipts identify `sky-calendar-aspect/v1-2026-11-09` and the
standard's source hash. Rechecking existing text does not generate or replace it.
The document is indexed as a rule in the owner-only Memory graph; it is neither
a new positive prose benchmark nor approval of generated wording.

`test-sky-aspect-writing-standard.mts` intercepts both provider transports at the
actual shared handler and exercises the CMS generator transports. It covers the
five major aspect inputs, complete source/fact delivery, preserved schema and
rhetorical rules, optional paragraphs/endings, scope isolation and denied access.
Existing aspect, saved-editor, memory, reader and full release gates still apply.
These checks establish instruction delivery and contract preservation. They do
not establish better literary quality; no paid prose comparison or new judge
calibration is part of this update.
