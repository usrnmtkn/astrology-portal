## Private correction handling

Four owner-quoted rejected passages and their exact reasons were recorded using
the existing versioned, idempotent private rejection RPC with actual thread
provenance. The protected store readback confirmed exact text and reasons.
They target the Libra Sun ingress only. This does not approve replacement prose,
create a reader draft, or make the rejected dates factual authority.

Raw rejection bodies and private fixtures are excluded from Git and public
receipts. Local tests receive the selected records in process memory. The full
unsaved preview is not retained as a file or correction record. Automatic
approval review rejected that proposed retention under the owner's no-save
instruction; verification uses only the explicitly quoted passages.
