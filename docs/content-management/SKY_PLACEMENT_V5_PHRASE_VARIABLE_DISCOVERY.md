# Editable phrase-variable discovery

Content Studio keeps authored phrase variables visibly separate from calculated Sky facts.

In the Sky placement composition reference, **Editable phrase variables** appears immediately below **Calculated Sky variables**. The accordion is sourced from the same Writing Library registry as the editor and shows each exact variable name, description, and reuse scope.

The registry is intentionally reference-only on the composition map. Edit phrase values in **Writing library & placement composition** for the selected planet and sign; use the accordion to find the exact source name without hunting through Advanced source tools.
