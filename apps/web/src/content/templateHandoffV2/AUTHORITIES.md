# Authority and conflict resolution

This file establishes one instruction hierarchy.

1. The user's current request and repository facts.
2. `CODEX-IMPLEMENTATION-PROMPT.md` in this archive.
3. Files in `contracts/` in this archive.
4. `ACCEPTANCE-GATES.md` and tests in this archive.
5. `sources/tldr-astro-voice-spec.md`, when it does not conflict with items 1–4.
6. Source-bank and screenshot evidence under `sources/` and `references/`.

Older ZIP prompts, older template-system documents, generated reports, chat feedback, Codex status messages, screenshots of TLDR Astro failures, and current reader output are not authorities for reader copy.

The following earlier assumptions are withdrawn:

- source-key presence is sufficient for READY;
- generic planet/house keyword rows are direct clauses;
- one universal placement/transit paragraph can serve every surface;
- every available narrative beat must render;
- compact and expanded copy may be the same string;
- the full article belongs in the hero, TLDR, and Overview simultaneously;
- a Home planetary horoscope is equivalent to collective Sky copy;
- Moon phase and Moon sign can be merged;
- feedback or diagnostic prose can be pasted into content records.

When evidence is insufficient, return `SOURCE_GAP`. Do not resolve an authority conflict by inventing prose.
